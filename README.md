# melvynx.dev

Personal site of Melvyn Malherbe, built with [TanStack Start](https://tanstack.com/start).

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # outputs .output/
pnpm start      # serves the production build
```

Deployed on Dokploy from the `Dockerfile` (auto-deploy on push to `main`).
